# Valley Bridge Dental Practice — Remake

A polished, responsive static remake of the supplied Lovable site.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design
- `script.js` — mobile navigation

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Notes
The implementation keeps the supplied site's information architecture and practice details while refreshing typography, spacing, cards, navigation, CTA treatment, and responsive behaviour.

The two practice images currently reference the image assets from the supplied Lovable site. Download those assets into an `assets/` folder and change the two image URLs in `index.html` if you want the remake to be fully self-contained.
